# Music Player Application using Java

## Overview

This project is a desktop-based Music Player Application developed using Java and Swing as part of a Virtual Java Internship. The application provides a simple and user-friendly interface for managing and playing music files. It demonstrates the use of Object-Oriented Programming (OOP), Java Collections Framework, and GUI development using Java Swing.

## Features

* Music Library Management
* Song Information Storage (Title, Artist, File Path)
* Playlist Creation and Management
* Play, Pause, and Stop Controls
* User-Friendly Graphical Interface
* Song List Display
* Modular Class-Based Design
* Easy Navigation

## Technologies Used

* Java
* Java Swing
* Java Collections Framework
* Object-Oriented Programming (OOP)

## Project Structure

* `Song` Class – Stores song details.
* `Playlist` Class – Manages playlists and songs.
* `MusicLibrary` Class – Maintains the music collection.
* `MusicPlayerGUI` Class – Provides the graphical user interface.
